# bradhill.dev

Personal site for Brad Hill — Salesforce Developer & Agentforce Dev Lead (Melbourne).

Static single-page site, no build step, no dependencies. Hosted on GitHub Pages with the custom
domain `bradhill.dev` (see `CNAME`).

## Deploy
1. Push this folder to a public repo (e.g. `Bradels/bradhill.dev`).
2. Repo → Settings → Pages → Source: `main` / root.
3. Custom domain is set via the `CNAME` file (`bradhill.dev`).
4. Point DNS at GitHub Pages (see the application hub's deploy notes).

## Edit
Everything is in `index.html` (inline CSS). Update text/links there.
