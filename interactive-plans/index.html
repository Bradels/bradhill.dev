Brad HillVentures and what they taught me

Venture 02

Interactive plans

Plans any agent can write, and I can annotate from any device.

Partial success

The idea

The idea is simple: any agent can create, read, update and delete a plan document, and I can read and update it from any device.

The solution

I built it on my existing AI engineering infrastructure. Each plan is a hosted page I can comment on from my phone, and the agent can ask me questions directly, each with its own answer box and tappable options.

A backend captures every comment, and through MCP any building agent can read the plan, pick up my answers and update it.

The outcome

Partial success.

It does what it was built to do, but it surfaced a limit that wasn't technical: my attention.

The learnings

What went right

  • Letting the agent ask me questions directly worked. 135 of my 148 notes were answers to its questions, and any agent could pick up the plan and my answers where the last one left off.
  • It works well when I actually read the plans.

What went wrong

  • Plan fatigue. Having detailed plans for everything can be overwhelming, and it leads to fatigue in making the right decisions.
  • I really felt the limit of my attention when working on multiple personal projects.
